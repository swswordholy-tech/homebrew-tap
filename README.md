# Homebrew Tap for AgentsChat

Official Homebrew Cask tap for **AgentsChat Desktop** (macOS Apple Silicon & Intel, Apple Developer ID notarized).

## Install

```bash
brew install --cask swswordholy-tech/tap/agentschat
```

Or tap first and install:

```bash
brew tap swswordholy-tech/tap
brew install --cask agentschat
```
